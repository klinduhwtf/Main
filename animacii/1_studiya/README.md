# 1 СТУДИЯ — заставки

Справка о канале и его фирменном стиле: `ERTIS_spravka.md`.

## Вариант 3 — спокойный, в цветах ERTIS (`zastavka_v3.html` + `zvuk_v3.py`)

8 с, 1920×1080, 25p, звук 48 кГц стерео; ProRes/DNxHR — −23 LUFS, MP4 — −16 LUFS.
Цвета взяты с логотипа ERTIS (бирюзовый `#00B2CA`, жёлтый `#FDDB27`), «1» стоит в «листе» той же формы, что и знак канала.
Без ритма, без тряски и вспышек.

| Время | Картинка | Звук |
|---|---|---|
| 0–2,4 с | тёмно-бирюзовый фон, медленные линии «реки», плывёт свет | низкий гул в ре, нарастает «воздух» |
| 2,4–3,9 с | мягко проявляется «лист» с «1», затем жёлтый элемент | глубокий негромкий удар, раскрывается струнный аккорд |
| 3,3–5,3 с | «СТУДИЯ» проявляется шторкой, тонкая линия под словом | три редкие ноты фортепиано |
| 5,2–6,8 с | медленный световой проход | аккорд тянется |
| 7,2–8 с | уход в чёрный | затухание |

`kadry_v3.png` — раскадровка. Готовый файл: `out/1_studiya_v3.mp4`. Пересборка: `python3 zvuk_v3.py`, затем `node render.js v3 all`.

## Вариант 2 — со звуком (`zastavka_v2.html` + `zvuk_v2.py`)

7 с, 1920×1080, 25p, Rec.709 (16–235), звук 48 кГц, стерео.
Громкость: ProRes/DNxHR — −23 LUFS (EBU R128, для эфира), MP4 — −16 LUFS (для просмотра).

Звук синтезирован с нуля (без сэмплов и чужой музыки), темп 120 BPM, картинка сведена с ним по долям.

| Время | Картинка | Звук |
|---|---|---|
| 0–2 с | звуковая волна в центре, лучи пульсируют на долях | пульс, свип, дробь, «обратная тарелка» |
| 1,65–2 с | волна стягивается, сверху падает «1» | — |
| 2,0 с | «1» приземляется, вспышка, тряска | удар: саб + бочка + крэш + стэб |
| 2,45–3 с | «1» уходит в логотип | хвост удара |
| 2,75–3,4 с | буквы «СТУДИЯ» впечатываются по одной | тик на каждую букву |
| 3,5 с | блик по логотипу, под ним эквалайзер | финальный аккорд, колокольчик |
| 6,5–7 с | уход в чёрный | затухание |

`kadry_v2.png` — раскадровка. Готовый файл: `out/1_studiya_v2.mp4`.

Пересобрать звук: `python3 zvuk_v2.py` (нужны numpy и scipy) — он же обновит
`zvuk_v2_env.js`, огибающую, по которой двигаются столбики в кадре.
Пересобрать видео: `node render.js v2 all`.

## Вариант 1 — без звука (`zastavka.html`)

Длительность 7 с, 1920×1080, 25p, Rec.709, ограниченный диапазон (16–235). Без звука.

Идея: две точки (ведущий и гость) идут навстречу, встречаются во вспышке, из неё возникает «1» в кольце, затем собирается «1 СТУДИЯ» и подпись «Подкаст». В конце — затемнение за 0,5 с.

| Время | Что происходит |
|---|---|
| 0–1,25 с | две точки идут друг к другу по линии |
| 1,25 с | вспышка в момент встречи |
| 1,3–2,4 с | прорисовывается кольцо, поднимается «1» |
| 2,6–3,4 с | «1» уходит влево |
| 2,95–3,8 с | по буквам появляется «СТУДИЯ» |
| 3,55–4,9 с | акцентная линия и подпись «Подкаст» |
| 4,9–6,5 с | статика под монтаж |
| 6,5–7 с | уход в чёрный |

`kadry.png` — раскадровка ключевых моментов.

## Файлы
- `zastavka.html` — сама анимация. Цвета и шрифт задаются в `:root`, слово — в константе `WORD`, подпись — в `#tag`, размер цифры — в `ONE_SIZE`.
- `render.js` — рендер через Chromium и ffmpeg.
- `out/1_studiya_zastavka.mp4` — готовый H.264.

## Рендер
```
node render.js v3 all     # вариант 3 со звуком: MP4, ProRes, DNxHR, PNG
node render.js v2 all     # вариант 2 со звуком: MP4, ProRes, DNxHR, PNG
node render.js mp4        # вариант 1: H.264 MP4
node render.js prores     # ProRes 422 HQ .mov (~160 МБ)
node render.js dnxhd      # DNxHR HQX .mov (~155 МБ)
node render.js png        # PNG-секвенция
node render.js all 25     # всё сразу; второй аргумент — fps (25 или 50)
```
ProRes и DNxHR в репозиторий не кладутся: больше лимита GitHub в 100 МБ.
