# ТЕЛЕЦЕНТР — заставка

Новая заставка передачи «Телецентр» (ERTIS) в той же системе, что и «1 СТУДИЯ» v4 (`../1_studiya/`): синяя гамма, стеклянные панели, перспективная сетка, бирюзовые акцентные линии ERTIS, тот же шрифт (Inter Display) и та же оркестровая основа звука. Обе заставки выглядят и звучат как одна линейка оформления канала.

9 с, 1920×1080, 25p, Rec.709 (16–235), звук 48 кГц стерео; ProRes/DNxHR — −23 LUFS, MP4 — −16 LUFS.

## Что заменено в старой заставке

Старая (по финальному кадру на превью ролика): серый фон с гранжевыми брызгами, стоковые киноплёнки в перспективе, клипарт-вышка в кольце, белая надпись с плоской тенью поверх вышки.

| Было | Стало |
|---|---|
| серый фон, грязные брызги | глубокий синий фон, мягкий свет, едва заметное зерно |
| стоковые киноплёнки | стеклянные панели и перспективная сетка, как у «1 СТУДИИ» |
| клипарт-вышка, залитая синим | вышка из тонких светящихся линий, рисуется снизу вверх |
| кольцо вокруг вышки | бирюзовые дуги сигнала у маяка и волны эфира через весь кадр |
| надпись перекрывает вышку, плоская тень | надпись под вышкой по сетке, разрядка, бирюзовые линии по бокам |

## Тайминг

| Время | Картинка | Звук |
|---|---|---|
| 0–3,2 с | камера пролетает сквозь стеклянные панели над сеткой | гул в ре, «воздух», нарастает дробь литавр |
| 0,9–3,2 с | вышка прорисовывается снизу вверх, по ней поднимается свечение | восходящий перелив челесты |
| 3,2 с | загорается маяк, горизонтальный блик, первая волна эфира | глубокий удар, аккорд Dsus2, «сигнал» |

| 4,4–6 с | «ТЕЛЕЦЕНТР» собирается из широкой разрядки, по бокам бирюзовые линии | аккорд разрешается в ре мажор |
| 5,8–7,2 с | блик по логотипу | тихий высокий звон |

| 8,3–9 с | уход в чёрный | затухание |

## Файлы и пересборка
- `zastavka.html` — анимация. Слово — константа `WORD`, геометрия вышки — `T_H`, `T_BASE`, `T_TOP`, `MAST`, `LEVELS`, тайминги — в начале скрипта. Проверка сетки: открыть в браузере, в консоли `render(7.5); showGrid()`.
- `zvuk.py` — звук (нужны numpy и scipy), пишет `zvuk.wav`.
- `render.js` — рендер через Chromium и ffmpeg.
- `kadry.js` — раскадровка в `kadry.png`.

```
python3 zvuk.py
node render.js all      # MP4, ProRes 422 HQ, DNxHR HQX, PNG-секвенция
node render.js mp4      # только MP4
node kadry.js
```
ProRes и DNxHR в репозиторий не кладутся: больше лимита GitHub в 100 МБ.
