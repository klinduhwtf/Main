# ТЕЛЕЦЕНТР — заставка «Два голоса»

«Телецентр» на ERTIS — прямой эфир с гостями: в студии обсуждают проблемы и ищут пути решения ([страница проекта](https://ertistv.kz/ru/projects/Telecentr)). Поэтому заставка рассказывает про разговор, а не про технику: два голоса идут навстречу, и там, где они встречаются, вырастает казахский орнамент «қошқар мүйіз» (бараньи рога), в узле вспыхивает жёлтый «лист» из знака ERTIS.

Своя, а не копия «1 СТУДИИ»: светлая тёплая гамма вместо тёмно-синего стекла, плоская графика из линий, национальный узор, звук на домбре. Общее с каналом — только фирменные бирюзовый и жёлтый и шрифт Inter Display.

10,1 с, 1920×1080, 25p, Rec.709 (16–235), звук 48 кГц стерео; ProRes/DNxHR — −23 LUFS (эфирная норма), MP4 — −17,9 LUFS (на 20% тише прежней версии).

## Откуда идея

- Казахстанские каналы сейчас уходят к сдержанным цветам и национальному орнаменту в современной подаче: «31 канал» в 2026 году построил знак на мотиве «құсқанат» (крылья птицы), агентство MOVATORS idea farm ([Designer.kz](https://designer.kz/2026/08/the-new-image-of-the-31st-what-will-the-tv-channel-look-like-after-the-redesign/)).
- Бирюзовый и жёлтый — цвета знака ERTIS и всей корпорации Qazaqstan ([Forbes.kz](https://forbes.kz/news/newsid_153183)).
- «Қошқар мүйіз» — самый узнаваемый мотив казахского орнамента. Здесь он нарисован одной линией той же толщины, что и голоса и линия под словом, — без «этно-обоев», как часть графики.

## Что было и что стало

| Было (по превью ролика) | Стало |
|---|---|
| серый фон, гранжевые брызги | тёплая светлая «бумага», мягкий бирюзовый свет |
| стоковые киноплёнки | две линии-голоса — суть передачи |
| клипарт-вышка в кольце | орнамент «қошқар мүйіз», вырастает из встречи голосов |
| надпись поверх вышки, плоская тень | надпись под знаком, тёмные буквы выезжают из-под линии |
| — | живая линия голоса под словом — «эфир идёт» |
| — | бирюзовая шторка с жёлтой кромкой — переход в студию |

## Тайминг

| Время | Картинка | Звук |
|---|---|---|
| 0,2–3,3 с | слева и справа плавно входят две линии-голоса, волна нарастает | перекличка двух фраз домбры, слева и справа, тихо нарастает |
| 3,3 с | голоса встречаются, вспыхивает жёлтый «лист» | удар по струнам + низкий удар |
| 3,3–4,5 с | из узла вырастает «қошқар мүйіз» | нарастающий бой домбры, открывается подложка |
| 4,5–5,5 с | узор уходит наверх | — |
| 4,95–5,8 с | «ТЕЛЕЦЕНТР» выезжает снизу | аккорд |
| 5,8–9,3 с | под словом живая линия голоса | спокойный ритм домбры |
| 9,3–10,1 с | бирюзовая шторка закрывает кадр | свист и финальный удар |

Финал — чистый бирюзовый кадр: из него удобно сделать склейку в студию. Если нужен финал на логотипе, убрать вызов `wipe(t)` и поставить `END` около 9,5.

`kadry.png` — раскадровка. Готовый файл: `out/telecentr.mp4`.

## Файлы и пересборка
- `zastavka.html` — анимация. Тайминги, цвета, слово, размеры узора — в начале скрипта; форма узора — функция `spiral` и массив `ORN`. Проверка сетки: открыть в браузере, в консоли `render(6); showGrid()`.
- `zvuk.py` — звук (нужны numpy и scipy): домбра синтезирована щипковой моделью Карплуса — Стронга, без сэмплов. Пишет `zvuk.wav`.
- `render.js` — рендер через Chromium и ffmpeg.
- `kadry.js` — раскадровка в `kadry.png`.

```
python3 zvuk.py
node render.js all      # MP4, ProRes 422 HQ, DNxHR HQX, PNG-секвенция
node render.js mp4      # только MP4
node kadry.js
```
ProRes и DNxHR в репозиторий не кладутся: больше лимита GitHub в 100 МБ.
