# ТЕЛЕОРТАЛЫҚ / ТЕЛЕЦЕНТР — заставка «Вышка»

«Телецентр» на ERTIS — прямой эфир с гостями: в студии обсуждают проблемы и ищут пути решения ([страница проекта](https://ertistv.kz/ru/projects/Telecentr)). Название — по-казахски «Телеорталық», по-русски «Телецентр», и снимаем мы на вышке. Заставка связывает всё это в одну линию:

1. Два голоса — две бирюзовые линии речи — плавно идут навстречу с краёв кадра.
2. У подножия они не встречаются, а поднимаются вверх двумя ногами вышки, появляются поперечины и раскосы.
3. На вершине голоса сходятся — вспыхивает маяк, жёлтый «лист» из знака ERTIS.
4. Из вершины вырастают рога «қошқар мүйіз» — сигнал, который уходит в эфир.
5. Под вышкой выезжает «ТЕЛЕОРТАЛЫҚ», под ним живая линия голоса и «ТЕЛЕЦЕНТР» в разрядку.
6. Бирюзовая шторка с жёлтой кромкой — переход в студию.

Смысл: разговор двух сторон поднимается до вершины, а там встреча даёт решение и сигнал для зрителей.

10,4 с, 1920×1080, 25p, Rec.709 (16–235), звук 48 кГц стерео; ProRes/DNxHR — −23 LUFS (эфирная норма), MP4 — −18 LUFS.

Предыдущая утверждённая версия «Два голоса» (без вышки, с орнаментом в центре) сохранена в `checkpoint_dva_golosa/`.

## Стиль

- Светлая тёплая «бумага», плоская графика одной линией: голоса, ноги вышки и рога одной толщины.
- Цвета ERTIS и корпорации Qazaqstan — бирюзовый и жёлтый ([Forbes.kz](https://forbes.kz/news/newsid_153183)), тёмные чернила для названий, шрифт Inter Display.
- Орнамент в современной подаче — так сейчас обновляются казахстанские каналы: например, знак «31 канала» на мотиве «құсқанат» ([Designer.kz](https://designer.kz/2026/08/the-new-image-of-the-31st-what-will-the-tv-channel-look-like-after-the-redesign/)).
- Звук на домбре, синтезированной с нуля.

## Тайминг

| Время | Картинка | Звук |
|---|---|---|
| 0,2–3,0 с | слева и справа плавно входят голоса, волна нарастает | перекличка двух фраз домбры, слева и справа |
| 3,0–3,9 с | голоса поднимаются ногами вышки, появляются поперечины и раскосы | две восходящие линии домбры сходятся к центру |
| 3,9 с | ноги сошлись на вершине, вспыхивает жёлтый маяк | удар по струнам + низкий удар |
| 3,9–5,0 с | над вершиной вырастают рога «қошқар мүйіз» | нарастающий бой домбры, открывается подложка |
| 5,0–6,0 с | вышка уходит наверх | — |
| 5,4 с | выезжает «ТЕЛЕОРТАЛЫҚ» | аккорд |
| 6,1 с | под словом живая линия голоса | спокойный ритм домбры |
| 6,4 с | выезжает «ТЕЛЕЦЕНТР» | тихий щипок |
| 9,6–10,4 с | бирюзовая шторка закрывает кадр | свист и финальный удар |

Финал — чистый бирюзовый кадр под склейку в студию. Если нужен финал на логотипе, убрать вызов `wipe(t)` и поставить `END` около 9,8.

`kadry.png` — раскадровка. Готовый файл: `out/telecentr.mp4`.

## Файлы и пересборка
- `zastavka.html` — анимация. Тайминги, цвета, названия (`WORD_KZ`, `WORD_RU_TEXT`) и размеры — в начале скрипта; вышка — `T_H`, `T_B`, `MAST`, `hw`, `BARS`; рога — `HORN`. Проверка сетки: открыть в браузере, в консоли `render(8); showGrid()`.
- `zvuk.py` — звук (нужны numpy и scipy): домбра — щипковая модель Карплуса — Стронга, без сэмплов. Общий уровень — `VOLUME`. Пишет `zvuk.wav`.
- `render.js` — рендер через Chromium и ffmpeg.
- `kadry.js` — раскадровка в `kadry.png`.

```
python3 zvuk.py
node render.js all      # MP4, ProRes 422 HQ, DNxHR HQX, PNG-секвенция
node render.js mp4      # только MP4
node kadry.js
```
ProRes и DNxHR в репозиторий не кладутся: больше лимита GitHub в 100 МБ.

## Проверить перед эфиром
- Написание: «ТЕЛЕОРТАЛЫҚ» — с казахской «Қ» на конце.
- Звук синтезирован и проверен по уровням, но не прослушан человеком — послушать до эфира.
